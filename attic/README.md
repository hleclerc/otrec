# attic

Everything otrec held before it was reduced to the projection-based reconstruction ( November 2026 ): the earlier
reconstructions ( diracs, disks, halo, meshes, `HcReconstruction`, `reconstruction2d` / `reconstruction3d`, the grid
transport of balls ), their phantoms, experiments, benches, docs and tests. Nothing here is imported by `src/otrec`.

The old package is still importable for the scripts that need it, in place of the new one:

    PYTHONPATH=attic/src python ...
